BIRTHDAY SURPRISE WEBSITE — SABA

1. Keep all files in this folder together.
2. Open index.html in Chrome/Edge/Safari.
3. For the best experience, open it on a phone in portrait mode.
4. Videos are included locally, so they do not need separate uploads.
5. The Google Fonts import is optional; if offline, the site uses fallback fonts.

Tip: upload the whole folder to a static hosting service if you want to send Saba a link.
